I’m Ze Jing, a final-year Game Development student at Amsterdam University of Applied Sciences.

Check Man started as a C# chess puzzle. The browser version keeps the original rules: a piece still has a cost, blockers still get in the way, and the puzzle only works if every target can be reached.

In Trust Protocol, I built a desktop where an email, a phone call, and a website all compete for your attention. One design question was what the player could see before being asked to make a choice. I kept the window and call logic separate from the interface so I could test what happens when a window closes or a call is missed.
